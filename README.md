# MEMORY GAME - 4°4 - GRUPO 1
## DESCRIPCION DEL PROYECTO 
Memory game es un juego en el cual el jugador tiene que ir encontrando pares de cartas en un tablero, las cuales se encuentran volteadas al menos que las toque.
El objetivo del jugador es encontrar todos los pares, memorizando las cartas que voltea para encontrar su otra mitad restante. Finaliza una vez que el usuario encuentra todos los pares posibles de cartas en el
menor tiempo posible.
## STACK TECNOLOGICO
- **Lenguaje**: C#
- **Framework**: MonoGame 3.8
- **Base De Datos**: MySQL
- **IDE**: Visual Studio 2022 / Visual Studio Insiders 2026
